One sentence explaining the modern internet to a traveler who has just stepped out of the year 1800, built only from things they already know: libraries, post offices, market stalls, letters, and roads.

`main.ts` (Node) writes the sentence to `/output/entry.txt`:

> Imagine every library, post office, and market stall on earth joined by one invisible road, so a letter written at breakfast is read in Canton before supper — and any stranger can write back.

191 characters. Run it with `node main.ts`.
